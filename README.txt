StayEasy - Next.js Hotel Booking Prototype

วิธีเปิดใช้งาน:
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ stayeasy ใน VS Code
3. เปิด Terminal แล้วรัน: npm install
4. รัน: npm run dev
5. เปิดเว็บ: http://localhost:3000

ไฟล์หลัก:
- app/page.js       หน้าจอและการทำงานของ Prototype
- app/globals.css   รูปแบบและการตกแต่ง
- app/layout.js     Layout และ metadata
- package.json      รายการ dependencies

หมายเหตุ: เป็น Frontend prototype ใช้ข้อมูลตัวอย่างและยังไม่มีฐานข้อมูลหรือระบบชำระเงินจริง
